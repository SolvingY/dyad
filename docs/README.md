# Docs

Where each kind of note lives. Add a line here when you add a doc.

**Every change leaves a record.** How to write it, for Claude, Lovable and people alike:
[operations/change-records.md](operations/change-records.md).

| Folder | What goes in it |
| --- | --- |
| `operations/` | Runbooks (SOPs): how to do a task safely, step by step. Template: `operations/_TEMPLATE.md`. |
| `decisions/` | One short dated note per decision: Decision, Why, Not doing, Where. Template: `decisions/_TEMPLATE.md`. |
| `changes/` | One change record per request: Why, What changed, How it works, How to check it, Deploy steps, Rollback, Open items. Template: `changes/_TEMPLATE.md`. |
