# Decisions

One file per decision, named `YYYY-MM-DD-short-name.md`, newest at the top of the list
below. Write one whenever a choice would surprise someone reading the code later: a
rule, a trade-off, something deliberately left out. Start from `_TEMPLATE.md`, link the
change record it belongs to, and follow `docs/operations/change-records.md`.

Each note answers four things in a few lines:

- **Decision:** what was decided.
- **Why:** the reason, with the evidence if there was any.
- **Not doing:** what this rules out, and anything left for later.
- **Where:** the files, PRs or settings it touches.

Don't rewrite an old decision. If it changes, add a new note and link back to the old one.
